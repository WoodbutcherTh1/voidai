# 🤖 VoidAI

VoidAI is a modern multilingual AI chat app built with Next.js and OpenRouter.

## ✨ Features

- 🌍 Multilingual AI replies
- 🧠 Language memory
- 🎭 Personality system prompt
- 😊 Emoji picker
- 💬 Real-time chat UI
- ⚡ Streaming responses
- 📜 Auto scroll

## 🚀 Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- OpenRouter API

## 📦 Installation

```bash
git clone https://github.com/WoodbutcherTh1/voidai.git
cd voidai
npm install
npm run dev
```
