# 🤖 VoidAI

VoidAI is a modern AI workspace built with Next.js, TypeScript, and OpenRouter.

A sleek multilingual AI interface inspired by modern productivity and chat apps, designed for chatting, development workflows, media tools, and future AI utilities.

---

## ✨ Features

### Core AI
- 💬 Real-time AI chat
- ⚡ Streaming responses
- 🌍 Multilingual replies
- 🧠 Language memory
- 🎭 Personality system prompts

### UI / UX
- 📱 Responsive design
- 🧭 Sidebar navigation
- 🔻 Bottom navigation
- 😊 Emoji picker
- 📜 Auto-scroll chat
- ⌨️ Keyboard shortcuts

### App Sections
- 💬 Chat workspace
- 👨‍💻 Dev tools page
- 🎵 Music page
- 🎬 Media page
- 🤖 Android tools page

---

## 🛠 Tech Stack

- Next.js 15
- React
- TypeScript
- Tailwind CSS
- OpenRouter API

## 🚀 Installation

```bash
git clone https://github.com/WoodbutcherTh1/voidai.git
cd voidai
npm install
npm run dev
```

Open locally:

```bash
http://localhost:3000
```

---

## 🔑 Environment Variables

Create `.env.local`

```env
OPENROUTER_API_KEY=your_api_key_here
```
